# Security Policy

## Supported Versions

This is a personal project. Security fixes are considered for the current
`main` branch only.

## Reporting A Vulnerability

Please do not attach credentials, tokens, raw NBA payloads, DuckDB files,
generated exports, or private data to public issues.

If you find a vulnerability that could expose local files, credentials, private
data, or unsafe CI behavior, use GitHub private vulnerability reporting for this
repository. For ordinary reproducible bugs, use the bug report issue template.
